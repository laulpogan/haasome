# Haasome presentation scope

Give knowledge a place: visit an object, recover its source-backed detail, and
revisit the chapter later. The current main demo is **Fragments of an Emperor**,
a licensed modern scan of the Capitoline courtyard with three manually curated
artifact regions and museum notes. The presenter selected this route after seeing
that the improved Austin reconstruction remained too rough.

The release is `release/museum-demo`, based on Euler's verified `affeb0f`.
Coordinator owns this branch. Its finish line is a stable three-stop route,
source reveal, recall, portable freeze/reopen, device persistence, clear attribution,
and a repeatable presentation. No new training, models or dependencies are required.

The original memory-palace vision remains supported by the separate Austin work:
selected photos/video, app-source evidence and a captured room. That implementation
is preserved on `integration/demo-polish`; automatic recognition is unfinished.
The historical demo does not claim that computer use captured the museum notes,
that our trainer created this scan, or that the scan depicts ancient Rome.

One human collaborator owns the proposed script and live feedback in GitHub issue
#1. The coordinator must distinguish proposed narration, automated action checks,
and an actual spoken rehearsal. Original lane plans and capsule reports record
prior experiments; README and docs/DEMO.md define the current stage route.
