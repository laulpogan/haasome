## Project description

Haasome gives personal memories a place to live. Our Austin MVP turns a real soccer field into a place to revisit a trip: navigate Apple's interactive 3D map, select memory points, and open the original goal photo, match video, or team photo. Personal notes and placements connect what happened with where the presenter wants to remember it.

The demonstration is a local macOS app built with AppKit, MapKit and AVKit. Apple provides the 3D map; we built the personal memory experience around it. Computer use in Codex helped gather selected WhatsApp trip media and inspect the selected field photo in Photos. Its exported GPS metadata located the field. The first pin placements are mnemonic cues, not verified exact event coordinates. The app consumes the resulting local records and does not call an AI model at runtime.

## How we used OpenAI

GPT-6 Astra in Codex helped us understand the repository, develop and integrate the experience, inspect selected source-app content, and debug the working prototype. For Tito, a Berkeley MBA student new to coding, the combination of explanation, computer use and implementation made it possible to contribute and continue the build. Our final Austin demo uses saved outputs of those computer-use sessions; we do not claim a live autonomous ingestion service or an Astra API inside the app.
