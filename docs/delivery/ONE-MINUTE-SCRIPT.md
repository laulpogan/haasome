# Haasome — Austin demo script

Tito records and narrates this video. Target: 55–60 seconds; 118 spoken words. The local video, explore/reveal and save/reopen flows were verified on the presentation Mac.

## Spoken script

I wanted to relive our soccer trip to Austin, without digging through hundreds of messages.

This is Haasome: a place for those memories to live.

This is the actual field, in Apple’s 3D map. I can explore it, then return to Martín’s goal through this photo.

Another point brings back our save against MIT, with the original video. And this one brings the team back together.

I can add what I remember and save it with that place. When I come back, the memory is still there.

We used Astra in Codex to build the prototype, and computer use to gather selected trip media and locate the field.

Haasome connects a place, a moment, and your own story.

## What to show

| Time | Action |
| --- | --- |
| 0–9s | Start with the field already loaded. Explain the trip and introduce Haasome. |
| 9–22s | Move around the 3D field; select Martín’s goal and show the photo. |
| 22–35s | Select the MIT save; play about three seconds. Select the team photo. |
| 35–46s | Show a short personal note, save it, return to the field and revisit the memory. |
| 46–60s | End on the field while explaining Astra/computer use and the final line. |

Wait for Apple's imagery to finish loading before recording. Record only the Haasome window with microphone narration. Keep the video's original audio quiet enough to hear the narration. Speak naturally; cut a sentence instead of rushing.

## Accurate claims

- Apple supplies the interactive 3D map. We did not train a reconstruction of this field.
- Selected trip photos/videos and a location from the selected Photos image inform the memories. Computer use happened in Codex; the MVP opens the resulting local media.
- The initial pins are memory cues within the field, not verified exact positions of each event.
- This is a local Mac MVP. The website can showcase the recording; it cannot iframe the native app.
