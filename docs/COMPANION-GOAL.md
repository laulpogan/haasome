## Find the chapter

Begin with the partner's selected trip if its locator and evidence are available.
Compare it against the existing July capsule. Inspect at most three bounded event
candidates; stop when one has a useful story and independent support across sources.
Use these criteria in order: source support, meaningful relationship between records,
clear chronology, personal relevance, and presentation quality. Do not invent a
numerical confidence score or claim this search found an objectively perfect event.

Use native Photos and WhatsApp through actual computer use. Follow one promising
caption, date or place into a bounded source check. Distinguish photo capture time,
message time, source-read time and capsule freeze time. Check timezone and available
geotags. A shared date, group title, face or nearby coordinate does not establish
attendance, identity or location. Preserve contradictions and unresolved claims.

Inspect Langfuse only through an available authorized UI or read-only connector,
using the selected task/session and date window. It belongs in the capsule only if
it explains a relevant search, decision, correction or outcome. Today's agent turns
may document how an old memory was recovered; they are not evidence that the old
event happened. If unrelated or inaccessible, omit it and state that limit.

Select three to five records covering as many of these useful angles as the evidence
supports: what was planned, what a photo preserves, where/when it occurred, what
changed or happened, and what a later reflection or agent investigation clarified.
Require at least two source types for a cross-source claim. Keep plans distinct from
results. Prefer one illuminating contradiction to several decorative records.

## Split work without competing for the computer

This session owns personal-source discovery, capture, synthesis, and capsule
integration in its own worktree. Companion owns scene selection, orientation,
reconstruction and GPU work in its worktree. Ask companion for one verified scene
bundle with provenance, initial camera pose and exact paths. Keep the existing
licensed scene if a new room is not ready or not relevant.

Agree who owns the foreground UI before either session clicks. Only one agent drives
native apps at a time. While one captures, the other can inspect code, artifacts,
licenses, training outputs or tests. Coordinate any viewer edits with its current
writer; don't assume a teammate lane is idle. No recursive agent fanout.

Use existing compute only for a named missing result that shortens delivery. Do not
start a trainer or model service merely because a GPU is free. Do not stop jobs,
change drivers, spend API credits, or send private captures to another machine or
vendor without the required specific authorization.

## Build and prove the smallest complete loop

Reuse `export_memory.py`, `assemble_capsule.py`, the existing contract and real
viewer. Save selected media plus contextual UI evidence locally; verify the saved
files decode. Capture is read-only: no messages sent or source records changed.
Retain source locators and short, attributable claims. Keep private content out of
Git and distinguish reconstructed, licensed and imagined settings.

Place three to five records on recognizable loci in one scene. Freeze one named
portable capsule. Use the native file picker if browser file-selection automation
fails. Reopen the actual file in the presenter's browser, display its photo and chat
evidence, run cue → visit → reveal, save, reload and verify persistence. Exercise
only necessary tests and inspect the rendered result. Don't substitute fixtures or
shell execution for observed source-app computer use.

Commit and push each verified source unit; merge to default only when asked. Finish
with the open working viewer, local snapshot path, branch/commit, short explanation
of why this chapter won, measured capture/assembly/load times where available, and
remaining uncertainty. The frozen snapshot is the deliverable. A plan, training run,
JSON schema or screenshot by itself is not completion.
